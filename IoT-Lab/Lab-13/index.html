Why?

Why does an IoT system need a database?

Imagine a smart classroom that measures temperature and humidity every minute. The readings should be saved so we can check them later. A database organizes those readings in a table.

Temperature = 25°C→Save reading→Find readings above 30°C

Raspberry Pi is a small Linux computer. MySQL is database software. SQL is the language used to create, save, search, and change data.

No Raspberry Pi? Complete the four tasks using the built-in SQL practice simulator below. It demonstrates selected SQL commands locally in your browser; it is not a real MySQL server or Raspberry Pi.

Four SQL commands to know

CREATE TABLE creates the table. INSERT adds readings. SELECT displays readings. UPDATE changes a saved reading.

CREATE TABLE readings (id INT, temperature INT, humidity INT); INSERT INTO readings VALUES (1, 25, 60); SELECT * FROM readings; SELECT * FROM readings WHERE temperature > 30; UPDATE readings SET temperature = 32 WHERE id = 1;

Optional: Real Raspberry Pi setup (instructor demonstration)

On a Raspberry Pi running Raspberry Pi OS, a commonly available MySQL-compatible server is MariaDB:

sudo apt update sudo apt install mariadb-server sudo systemctl enable --now mariadb sudo mariadb

These Linux commands require a real Raspberry Pi or compatible Linux environment, administrator access, and package availability. In the database shell, you can create a database with CREATE DATABASE iot_lab; and select it with USE iot_lab; before creating the table. The browser simulator skips server installation and database selection.
