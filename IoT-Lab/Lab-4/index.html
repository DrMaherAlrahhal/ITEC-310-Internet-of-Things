1. What are we doing?

We will use an Arduino Uno to turn an LED ON and OFF repeatedly. This is called blinking.

Arduino → Digital Pin 13 → LED → GND

Why? IoT systems use the same idea to control lights, alarms, and other output devices.

2. Build the circuit in Wokwi

Open Wokwi → New Project → Arduino Uno. Add an LED and a 220 Ω resistor.

Arduino D13 → 220 Ω resistor → LED A (+) → LED C (−) → Arduino GND

Important: A = Anode (+), C = Cathode (−). Connect the resistor in series with the LED. In Wokwi, click the components and pins to connect wires.

3. Arduino code – Blink the LED

int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}
CommandMeaning
pinMode(ledPin, OUTPUT)Prepare pin 13 to control the LED.
digitalWrite(ledPin, HIGH)Turn LED ON.
digitalWrite(ledPin, LOW)Turn LED OFF.
delay(1000)Wait 1000 milliseconds = 1 second.
loop()Repeat the blinking forever.

Run it: Paste the code into Wokwi and press the green Start Simulation button.
