1. Explore the protocol stack

Click any layer to see what it does. A protocol stack is a set of cooperating communication layers, not a single protocol.

ApplicationWhat message does the software want to exchange?
TransportHow is the message carried between endpoints?
NetworkWhere should the packet go?
Link / PhysicalHow does the signal cross the local connection?
Examples are illustrative: MQTT → TCP → IP → Wi-Fi is one common combination. CoAP often uses UDP. Not every IoT device uses the same stack.
