1. Learn the differences

Protocol Rules

Defines how messages are exchanged. Examples include MQTT for messaging and Bluetooth LE for short-range communication.

Question: Can the devices exchange messages?

Device profile Meaning

Describes capabilities, supported fields, data types, units, and behavior. Profiles help applications understand a device.

Question: Do both sides understand the data?

Compliance Evidence

Checks whether a product or implementation meets a specified set of requirements. A claim should be backed by appropriate tests and records.

Question: Can we demonstrate that requirements are met?

Interoperability is the goal

Devices from different systems or vendors should exchange and correctly interpret data. Using the same network does not automatically make them interoperable.
