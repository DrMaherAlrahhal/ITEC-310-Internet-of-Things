01 · Understand

Why do we need a PIR sensor?

Imagine a smart home. When someone walks into a room, we want the security system to notice movement and warn us automatically.

Person moves → PIR detects motion → Arduino reads signal → LED / buzzer alarm

👀 PIR sensor

Detects changes in infrared radiation associated with movement. It does not measure distance.

💡 LED

Provides a visual warning when motion is detected.

🔔 Buzzer

Provides a sound warning when motion is detected.

Simple rule: Motion detected = HIGH (1); no motion = LOW (0), after the sensor settles.

A PIR sensor may need a short warm-up period. In Wokwi, use the sensor's motion control to trigger movement.
02 · Connect

Arduino Uno + PIR + LED + Buzzer

Open Wokwi, create an Arduino Uno project, and add a PIR sensor, LED, resistor (220 Ω), and buzzer.

PIR sensor

VCC → Arduino 5V
GND → Arduino GND
OUT → Arduino D2

LED

Arduino D8 → 220 Ω resistor → LED anode (+)
LED cathode (−) → GND

Buzzer

Buzzer (+) → Arduino D9
Buzzer (−) → GND

Make sure the sensor, LED, and buzzer share Arduino GND. Follow the pin labels in your simulator.

03 · Instructor demonstration

Arduino program

Copy the code into Wokwi, start the simulation, and trigger the PIR sensor. The Serial Monitor shows the motion status.

const int PIR = 2;
const int LED = 8;
const int BUZZER = 9;

void setup() {
  pinMode(PIR, INPUT);
  pinMode(LED, OUTPUT);
  pinMode(BUZZER, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int motion = digitalRead(PIR);

  if (motion == HIGH) {
    digitalWrite(LED, HIGH);
    tone(BUZZER, 1000);
    Serial.println("Motion detected! Alarm ON");
  } else {
    digitalWrite(LED, LOW);
    noTone(BUZZER);
    Serial.println("No motion. Alarm OFF");
  }
  delay(500);
}
digitalRead(PIR)

Reads whether the PIR output is HIGH or LOW.

digitalWrite(LED, HIGH)

Turns the warning LED on.

tone() / noTone()

Starts or stops the buzzer sound.

if / else

Chooses what happens when motion is or is not detected.
