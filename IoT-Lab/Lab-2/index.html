Before starting

Open the Linux Terminal

On Ubuntu, press Ctrl + Alt + T or open the Terminal application. Commands are typed in the Terminal, not in a browser address bar.

 

This webpage explains and organizes your lab. Its command examples are not a real Linux Terminal; run commands on your own Ubuntu/Linux machine or VM.

Part 1 · Know your environment

Who am I? Where am I? What is here?

👤 Current user

whoami displays the logged-in username.

whoami

📍 Current location

pwd shows the full path to your current folder.

pwd

📁 Files & folders

ls lists visible contents.

ls

📋 More details

ls -l lists permissions, owner, size and other details.

ls -l

👁️ Hidden files

ls -a includes names beginning with a dot.

ls -a

🖥️ System information

Check date/time and Linux system details.

date
uname -a

Example Terminal output

student@ubuntu:~$ whoami
student
student@ubuntu:~$ pwd
/home/student
student@ubuntu:~$ ls
Documents  Downloads  Pictures

Illustrative output only. Your username and folders may differ.

Part 2 · Navigate

Move between folders using cd

Enter Documents

cd Documents

Go up one level

cd ..

Return home

cd ~

Journey: Home → Documents → Parent folder → Home. Use pwd after each move to verify the location.

Part 3 · Create and edit

Build your CSCI300 / Week2 folder structure

cd ~
mkdir CSCI300
cd CSCI300
mkdir Week2
cd Week2
pwd
Home
└── CSCI300
    └── Week2

Create → Write → Read → Edit

touch notes.txt
echo "Operating Systems Lab" > notes.txt
cat notes.txt
nano notes.txt

Inside nano, add your own lines. Save with Ctrl + O, press Enter, then exit with Ctrl + X. Run cat notes.txt again to confirm your changes.

echo ... > notes.txt replaces the file contents. To add a line without replacing existing text, use >>.

Other useful commands

clear

clear clears the visible Terminal screen.
