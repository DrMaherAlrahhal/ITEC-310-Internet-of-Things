2. What Is ESP32?

ESP32 is a small programmable microcontroller with built-in Wi-Fi and Bluetooth. It can connect to sensors and control outputs such as LEDs.

ESP32

Small board · GPIO pins · Wi-Fi · Bluetooth

Arduino Programming

We program the ESP32 using C/C++ syntax and the Arduino framework.

4. Arduino Program Structure

setup()

Runs once when the ESP32 starts. Use it to prepare Serial communication or pins.

loop()

Runs repeatedly while the simulation is running.

Basic Template

void setup() {
  // Runs once
}

void loop() {
  // Repeats continuously
}

Useful Functions

Serial.begin(115200)

Starts serial communication.

Serial.println("text")

Prints text on a new line.

delay(1000)

Waits 1 second (1000 milliseconds).

Example: Print a Message

void setup() {
  Serial.begin(115200);
}

void loop() {
  Serial.println("Hello IoT");
  delay(1000);
}
