5. Design the Right Network

Start with the application requirements—not with a favorite communication technology.

Application requirements→Network requirements→Communication choice→Complete architecture

Consider: range, amount of data, power consumption, number of devices, operating environment, and cost.

Wearable deviceShort range, small device, low power, often communicates with a nearby phone.
Smart farmLarge area, many outdoor devices, long-distance communication needs.
Smart classroomRoom/campus coverage, temperature and occupancy monitoring, dashboard access.
