1 · How do smart objects connect?

A smart object combines sensing or action with processing and a way to exchange information. Connections may be wired (between pins or boards) or wireless (between nearby or networked devices).

GPIOSimple digital input/output. Example: button input or LED output.
I²CShared SDA/SCL lines; addressed devices such as environmental sensors.
UARTSerial exchange through TX/RX; both ends need matching settings.
SPIClocked, short-range device interface; common for displays and modules.
Wi-Fi / BLEWireless connections. Wi-Fi can join a local IP network; BLE supports nearby low-power exchange.
MQTTApplication messaging: devices publish topics and subscribers receive messages via a broker.

A connection interface and an application messaging protocol solve different problems: for example, Wi-Fi provides network connectivity, while MQTT organizes messages over that network.

4 · Connection design checklist

Before selecting a connection, ask: How far? How much data? How much power? What reliability? Is Internet needed? How is access protected?

Short wired connectionConsider GPIO, I²C, UART, or SPI based on the peripheral interface.
Nearby wireless devicesConsider BLE if low-power, short-range communication fits.
IP network / remote viewConsider Wi-Fi for connectivity and MQTT or another application protocol for messages.

Question 1

Explain how an ESP32 can connect to smart objects using GPIO, I²C, and UART.

Model answer: GPIO uses input/output pins for simple signals such as reading a button or switching an LED. I²C connects addressed devices on shared SDA and SCL lines. UART exchanges serial data using TX and RX. The interface is chosen according to the device and its communication needs.

Question 2

Compare direct local connections with wireless connections between smart objects.

Model answer: Direct wired links can be simple and reliable over short distances but require cabling. Wireless links allow flexible placement but depend on range, interference, and power. Choose based on distance, mobility, data needs, and the operating environment.

Question 3

Design a smart classroom door-monitoring system using connected smart objects. Explain its message flow.

Model answer: A door sensor connects to an ESP32 input. The ESP32 detects a change and publishes an event through Wi-Fi using MQTT to a broker. A dashboard subscribes and displays the door status. A local buzzer can still operate without Internet. Access control and protected communication help secure the system.
