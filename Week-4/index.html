1. Physical world ⇄ digital system

A sensor observes. An actuator changes the physical world. The controller evaluates readings and decides what to do.

🌡️ Physical condition→Sensor→Controller / decision→Actuator→Physical action
Temperature sensorMeasures heat or cold.
Humidity sensorMeasures moisture in air.
Light sensorMeasures light level.
Motion sensorDetects movement.
Distance sensorMeasures distance to an object.
Soil moisture sensorMeasures water content in soil.

2. Choose by requirement, not price

Start with the physical condition the application needs to understand. Then evaluate the sensor's characteristics.

RangeMinimum and maximum values the sensor can measure.
AccuracyHow close a reading is to the real value.
Response timeHow quickly the sensor reacts to change.
EnvironmentIndoor, outdoor, moisture, heat, dust or vibration.
Power & communicationBattery needs and how readings reach the controller.
CostMeet requirements without unnecessary expense.

Try the range check

The application requires −20°C to 70°C. Can a sensor measuring 0°C to 50°C cover it?

3. Sensor & actuator selection challenge

Select an application to see its required measurement and physical action.

Important: the sensor and actuator are selected for different reasons. A sensor matches the measurement; an actuator matches the required physical action.

4. What makes an object smart?

Normal fanA person turns it ON or OFF manually.
Smart fan systemDigital sensing, processing or communication can support automatic operation and status updates.
Integrated designSensing, processing, communication and actuation are in one product.
Distributed designSensors, processing and actuators can be separate connected devices.

Smart does not necessarily mean AI. Digital capabilities and interaction with an IoT system make an object smart.
