1. Why do we need a relay?

Imagine a smart home: you want an Arduino to switch a small fan ON and OFF. The Arduino control pin cannot safely power a motor directly. A relay is an electrically operated switch that lets a control circuit switch a separate motor circuit.

Arduino signal → Transistor driver → Relay coil → Relay contact → Motor ON / OFF

Arduino

Sends an ON/OFF control signal.

Transistor

Drives the relay coil because the Arduino pin should not power the coil directly.

Relay

Opens or closes the separate motor power circuit.

DC Motor

Rotates when its power circuit is closed.

Think: What happens to the motor when the relay contact opens?

2. Build the circuit in Tinkercad

Open Tinkercad → Circuits → Create new Circuit. Search for these components:

Components

Arduino Uno, SPDT 5 V relay, NPN transistor (e.g. 2N2222), diode, 1 kΩ resistor, DC motor, 5 V motor supply, wires. Add a pushbutton for Task 4.

Control side

Arduino D8 → 1 kΩ resistor → transistor base. Transistor emitter → GND. Relay coil between +5 V and transistor collector. Place a flyback diode across the relay coil (stripe/cathode toward +5 V).

Motor side

Motor supply + → relay COM. Relay NO → motor +. Motor − → motor supply −. The motor is OFF until the relay is energized.

Important: Use only low-voltage simulated circuits. Do not connect a real motor or relay coil directly to an Arduino GPIO pin. Relay pin positions vary in Tinkercad: inspect the component labels before wiring. Connect Arduino GND to the driver supply GND. The motor's separate supply may remain isolated from the control circuit.

If your Tinkercad component list does not contain a ready-made relay module, use the relay + transistor + diode arrangement described above. Some simulations may require adjusting component settings.

3. Arduino code: Switch the motor ON and OFF

Open Code → Text in Tinkercad and use this example. Pin 8 controls the relay driver.

const int RELAY_PIN = 8;

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, LOW);
}

void loop() {
  digitalWrite(RELAY_PIN, HIGH); // Motor ON
  delay(1000);
  digitalWrite(RELAY_PIN, LOW);  // Motor OFF
  delay(1000);
}
pinMode(8, OUTPUT)

Prepare pin 8 to send an output signal.

digitalWrite(HIGH / LOW)

Switch the relay driver ON or OFF.

delay(1000)

Wait 1000 milliseconds = 1 second.

This code assumes an active-HIGH relay driver: HIGH energizes the relay. Some relay modules are active-LOW; their ON/OFF logic is reversed.
