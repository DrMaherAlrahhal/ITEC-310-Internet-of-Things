🧠

Runs programmed instructions and makes decisions.

📶

🌀

Changes the physical world when it receives a command.

These functions can be built into one product, split across local devices, or distributed across a connected system.

Hardware focus

MCU chip vs development board

🧠

Microcontroller (MCU)

The computing chip. Contains a processor, memory and programmable input/output connections.

Example: ESP32 chip
🔌

Development board

A ready-to-use board built around the MCU. Usually adds USB connection, power regulation, accessible pins and other support circuits.

Example: ESP32 DevKit
