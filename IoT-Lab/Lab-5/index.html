1. What are we learning?

Last week, we switched an LED ON and OFF. This week, we will make the same LED appear dim, medium, or bright.

From Blinking to PWM — Important Concept

In the previous lab, we used slow delays to turn the LED ON and OFF. With PWM, switching is fast and stable, and we adjust how long the signal stays ON during each cycle. This is called the Duty Cycle.

What is PWM?

PWM = Pulse Width Modulation. Arduino switches the LED ON and OFF very quickly. Changing the percentage of time it stays ON changes its perceived brightness.

More ON time → Brighter LED

Which Arduino function do we use?

Lab 4: Blinking
digitalWrite(9, HIGH);
delay(1000);
digitalWrite(9, LOW);
delay(1000);

Our program explicitly changes the pin state and waits between changes.

Lab 5: PWM
analogWrite(9, 128);

Arduino's hardware automatically generates rapid switching at approximately 50% duty cycle.

Why is it called analogWrite() if PWM is digital?

On Arduino Uno, analogWrite() generates a digital PWM signal on PWM-capable pins. It does not produce a continuously adjustable analog output voltage. Its 0–255 value sets the duty cycle.

2. Blinking vs PWM

Both methods switch an LED ON and OFF. The difference is how quickly the switching happens and what we observe.

3. Two Ways to Control LED Brightness

Analog Dimming

The LED remains ON while we change the current flowing through it.

Example: A suitable LED driver changes current from 5 mA to 10 mA, increasing brightness.

PWM Dimming

The LED switches ON and OFF rapidly while we change the duty cycle.

Example: Change the ON-time ratio from 25% to 75%.

Remember: Analog dimming changes current. PWM dimming changes the proportion of ON time. Both influence the average light output. In a real LED circuit, current and voltage are related; a resistor or driver must limit current.

Why use PWM?

It is easy to generate digitally, works well with many LED drivers, and allows repeatable dimming without requiring a continuously variable analog output pin.

4. Frequency, Pulse Width and Duty Cycle

Frequency

How many complete ON/OFF cycles occur in one second.

Frequency determines how fast the signal switches.

Pulse Width

The amount of time the signal remains HIGH during one cycle.

Duty Cycle

The percentage of each cycle that the signal stays HIGH.

Duty cycle determines the proportion of ON time.

Two sentences to remember

“The frequency determines how fast the signal switches.”

“The duty cycle determines how long the signal stays ON during each cycle.”

Arduino Uno PWM pins

Arduino Uno has six commonly used PWM-capable pins: 3, 5, 6, 9, 10, 11 (marked ~ on the board).

PinsTypical default PWM frequency
3, 9, 10, 11Approximately 490 Hz
5, 6Approximately 980 Hz

Different pins are linked to different internal timers, which can use different default settings. The 16 MHz processor clock is not the same as the PWM output frequency.

Example — Pin 9 at 490 Hz

There are approximately 490 complete PWM cycles per second. One cycle lasts about 2.04 milliseconds.

At 50% duty cycle: approximately 1.02 ms HIGH and 1.02 ms LOW in each cycle.

Quick thinking question

If a cycle lasts 10 ms, and HIGH lasts 2 ms while LOW lasts 8 ms, what is the duty cycle?

Show answer

20%. Duty cycle = 2 ÷ (2 + 8) × 100 = 20%.

5. What Do 0, 64, 128 and 255 Mean?

These numbers are PWM values, not volts and not seconds.

ValueApprox. duty cycleAppearanceTry it
00%OFF
6425%Dim
12850%Medium
255100%Brightest
Approximate duty cycle (%) = PWM value ÷ 255 × 100

For example: 64 ÷ 255 × 100 ≈ 25%.

These duty cycle percentages are approximate. Perceived brightness is not perfectly linear with the PWM value because human vision is nonlinear.

Starter Code — Medium Brightness

int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  analogWrite(ledPin, 128); // Medium brightness
}

Explain the Code — Line by Line

StatementMeaning
int ledPin = 9;Store the LED pin number in a variable.
void setup()Runs once when the Arduino starts.
pinMode(ledPin, OUTPUT);Configure pin 9 as an output.
void loop()Runs repeatedly.
analogWrite(ledPin, 128);Set the PWM duty cycle to approximately 50%.
Important: The value 128 is not a delay and is not a voltage. It sets the duty cycle. We do not need to repeatedly call digitalWrite(HIGH) and digitalWrite(LOW) because the PWM hardware performs the rapid switching.

Example — Alternate Dim and Bright (Task 3)

int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  analogWrite(ledPin, 64);  // Dim
  delay(1000);
  analogWrite(ledPin, 255); // Bright
  delay(1000);
}

The delay keeps each brightness setting for 1 second. It does not set the rapid PWM frequency.

Optional Example — Smooth Fade

int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  for (int brightness = 0; brightness <= 255; brightness += 5) {
    analogWrite(ledPin, brightness);
    delay(30);
  }

  for (int brightness = 255; brightness >= 0; brightness -= 5) {
    analogWrite(ledPin, brightness);
    delay(30);
  }
}

The first loop increases brightness; the second decreases it. Changing delay(30) to delay(15) makes the fade faster because the duty cycle changes more often.

10. Common Questions and Real-Life Applications

Does analogWrite(9, 128) output 2.5 V continuously?

No. The output alternates between approximately 0 V and 5 V. Its time-averaged voltage is about 2.5 V at 50% duty cycle, but the instantaneous output is digital.

Can we use any Arduino pin for PWM?

Not with the standard Uno analogWrite PWM behaviour. Use PWM-capable pins 3, 5, 6, 9, 10 or 11.

Does PWM damage the LED?

Normal PWM is suitable for LEDs when the circuit includes appropriate current limiting. Never connect an ordinary LED without a suitable resistor or driver.

Does 50% duty cycle always look exactly half as bright?

No. It gives roughly half the average LED ON time, but perceived brightness is nonlinear and depends on the LED, circuit and human vision.

Where is PWM used in real life?

LED dimming, decorative lighting, dashboard indicator brightness, display backlights, and some motor speed control systems.
