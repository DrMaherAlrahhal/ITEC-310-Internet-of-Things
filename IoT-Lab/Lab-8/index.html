PART 1 · LEARN

1. Why do IoT devices use Bluetooth?

Imagine a temperature sensor in a smart room. We want to see its readings on a nearby smartphone without a cable.

Sensor

Transfers data wirelessly over a short distance.

Smartphone

Receives and displays the sensor reading.

Important: This webpage demonstrates the Bluetooth data journey inside the browser. It does not establish a real Bluetooth radio connection to a smartphone. A real phone connection requires supported hardware and an appropriate Bluetooth app.

PART 2 · UNDERSTAND

2. How does the data travel?

  1. The sensor measures temperature.
  2. The microcontroller reads the sensor value.
  3. The Bluetooth connection sends the reading.
  4. The smartphone displays the received value.
Example message: Temperature: 28 C

Which board should we use?

An ESP32 is a practical example because many original ESP32 boards support Bluetooth. An Arduino Uno needs an external Bluetooth module, such as HC-05, for a classic Bluetooth serial setup.

This lab uses a simulated receiver to keep the activities easy and accessible without hardware.

PART 4 · CODE EXAMPLE

4. Understand the Arduino-Style Code

In this simple Wokwi ESP32 Serial Monitor exercise, the Serial Monitor acts as a stand-in for a receiving screen. It does not send data over Bluetooth.

int temperature = 25;

void setup() {
  Serial.begin(115200);
}

void loop() {
  Serial.print("Temperature: ");
  Serial.print(temperature);
  Serial.println(" C");
  delay(2000);
}

Try it: Open Wokwi, start an ESP32 project, paste this code into the Arduino sketch, and start the simulation. Open the Serial Monitor to view messages.

Serial.begin(115200)

Starts serial communication.

Serial.print()

Displays data in the Serial Monitor.

delay(2000)

Waits two seconds before repeating.
