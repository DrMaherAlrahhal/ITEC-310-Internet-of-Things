1. Why do we use a relay?

Arduino

Sends a small control signal from a digital output pin.

Relay

Acts as an electrically controlled switch for the motor's separate power circuit.

DC Motor

Runs when its power circuit is closed and stops when the circuit is opened.

Arduino control signal → Relay switch → Motor ON / OFF

Important: Never power a DC motor directly from an Arduino GPIO pin. Use an appropriate relay driver or relay module and a separate motor supply. For a bare relay, use a transistor driver and flyback diode. Tinkercad's available parts may differ.

2. Prepare your Tinkercad circuit

  1. Open Tinkercad Circuits and create or reopen your Lab 10 circuit.
  2. Use an Arduino Uno, relay or relay module, DC motor, and a suitable motor power supply.
  3. Use Arduino pin 7 to control the relay driver/input. Connect common grounds where required by your driver circuit.
  4. Connect the motor's separate power circuit through the relay's COM and NO contacts.
  5. For Task 4, connect a pushbutton between pin 2 and GND (using INPUT_PULLUP).

This is a connection guide, not a complete electrical schematic. If using a bare relay, include the transistor, base resistor, and flyback diode. If your relay module is active-LOW, the ON/OFF signal levels must be reversed.

3. Starting Arduino code

Assume a relay driver that turns ON when pin 7 is HIGH. The motor runs for 2 seconds and stops for 2 seconds, repeatedly.

const int relayPin = 7;

void setup() {
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, LOW);
}

void loop() {
  digitalWrite(relayPin, HIGH); // Motor ON
  delay(2000);
  digitalWrite(relayPin, LOW);  // Motor OFF
  delay(2000);
}

Remember: HIGH activates an active-HIGH relay driver; LOW deactivates it; delay(2000) waits 2 seconds; loop() repeats.
