02

Four Important Concepts

In IoT, four important concepts help different devices communicate and work correctly. A protocol defines how devices exchange messages, such as using MQTT. A profile describes the data format, units, and expected behavior of a device. Interoperability means different devices can exchange information and use it correctly, even when they come from different companies. Compliance means checking whether a device or system meets documented requirements and keeping evidence of the results.

03

IoT Device Profiles

An IoT device profile describes how information should be organized so that other devices and applications can understand it. For example, a university dashboard may expect temperature as a number, the unit as Celsius, and a profile version. If a sensor sends only {"temperature":28}, the dashboard may not know the unit or which profile version the sensor uses. A better message is {"temperature":28,"unit":"C","profile_version":"1.0"}. This helps the dashboard understand the data correctly.

Interoperability: Different Devices Working Together
Interoperability means that devices from different companies can communicate and correctly use each other’s information. For example, a temperature sensor from Vendor A sends 28°C, but a dashboard from Vendor B expects Fahrenheit. Although both devices are connected, they use different temperature units. The application can solve this problem by converting 28°C into 82.4°F. This allows both systems to work together even when they use different data formats or units.

05
Compliance: Can We Prove the System Works?
Compliance means checking whether an IoT device or system meets specific documented requirements. For example, before connecting a new temperature sensor to a university dashboard, the team should verify the communication protocol, data format, measurement units, security permissions, and system behavior. They should also test what happens when the network connection fails. The results must be recorded as evidence. Simply saying that a device works is not enough; the team needs test results to support its compliance claims.

06
The Complete IoT System
Imagine a university uses temperature sensors from different companies to monitor classrooms. First, the sensors use a communication protocol such as MQTT to send information. Next, device profiles define the expected temperature format and units. Interoperability allows the university dashboard to understand and use readings from different sensors. Finally, compliance testing checks whether the complete system meets its documented requirements. These four concepts help the university build an IoT system that communicates correctly and can be tested and verified.
