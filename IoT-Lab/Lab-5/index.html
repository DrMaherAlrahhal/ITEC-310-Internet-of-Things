1. What are we learning?

Last week, we switched an LED ON and OFF. This week, we will make it dim, medium, or bright.

What is PWM?

PWM = Pulse Width Modulation. Arduino switches the LED ON and OFF very quickly. Changing how long it stays ON changes the brightness we see.

Arduino command

analogWrite(9, value);

On Arduino Uno, use a PWM-capable pin such as 9. The brightness value ranges from 0 to 255.

Brightness values

0 = OFF
64 = dim
128 = medium
255 = brightest

Remember: On Arduino Uno, analogWrite() produces PWM on supported pins; it does not output a continuously varying analog voltage.

3. Build and Run in Wokwi

Components

Arduino Uno, LED, 220 Ω resistor, connecting wires.

Connections

Arduino Pin 9 → 220 Ω resistor → LED Anode (+)

LED Cathode (−) → Arduino GND

Connect the LED and resistor in series. The longer LED leg is usually the anode.

Open Wokwi

  1. Open wokwi.com.
  2. Create a new Arduino Uno project.
  3. Add an LED and a resistor.
  4. Connect the circuit using pin 9.
  5. Paste the code below and start the simulation.

Starter Code – Set LED Brightness

int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  analogWrite(ledPin, 128); // Medium brightness
}

What happens? The LED stays at medium brightness. Change 128 to another number between 0 and 255 to observe the difference.

Example – Smooth Fade (for Task 4)

int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  for (int brightness = 0; brightness <= 255; brightness += 5) {
    analogWrite(ledPin, brightness);
    delay(30);
  }

  for (int brightness = 255; brightness >= 0; brightness -= 5) {
    analogWrite(ledPin, brightness);
    delay(30);
  }
}

The first loop increases brightness; the second decreases it. delay(30) controls how quickly the change happens.
