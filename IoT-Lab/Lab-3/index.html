Week 3 · Remote Login Using SSH

Learn IP addresses, test connections with Ping, and control a remote Linux computer.

Computer A→ Network → SSH →Computer B / Raspberry Pi

Why do we need SSH?

Imagine a Raspberry Pi installed in a smart greenhouse. You want to check its temperature-monitoring program, but the device has no monitor or keyboard.

🚶 Without SSH

Go to the greenhouse → connect a monitor and keyboard → check the program.

🔐 With SSH

Stay at your laptop → connect over the network → check or fix the program remotely.

SSH (Secure Shell) lets you securely log in to a remote computer and execute commands on it.

SSH gives access to the remote computer. It does not directly operate sensors; programs running on that computer can manage sensors.

What can SSH do?

📁 View and manage files
🐍 Run Python programs
⚙️ Start or stop IoT applications
🛠️ Troubleshoot a remote system

For this class, a second Linux computer can replace a physical Raspberry Pi while learning SSH.

What is an IP address?

An IP address identifies a device on a network. An IPv4 address has four numbers separated by dots; each number is between 0 and 255.

192 . 168 . 1 . 20

Each part is one octet (0–255). Example addresses here are illustrative; use your actual computer's IP in the lab.

Find the Linux computer's IP

hostname -I

What does Ping do?

Ping sends small network test packets and checks whether another device replies.

Computer A→Test packet→Computer B
Computer A←Reply←Computer B
ping 192.168.1.20
64 bytes from 192.168.1.20: icmp_seq=1 ttl=64 time=1.2 ms
A reply means the device responded to Ping.
No reply does not always mean the device is offline: firewalls or network settings may block Ping. On Linux, press Ctrl + C to stop it.

How to connect using SSH

From Computer A, connect to the Linux account on Computer B.

ssh username@IP_address
ssh student@192.168.1.20

On the first connection, verify the remote host identity before accepting its key. If you trust and have verified it, enter yes. Then enter the remote user's password.

Computer B must be reachable and have an SSH server running, with permission to log in. Ping working does not guarantee SSH will work.

Commands after login

hostname

Remote computer's name

whoami

Logged-in username

pwd

Current folder location

ls

Files and folders

hostname
whoami
pwd
ls
exit

exit closes the SSH session and returns to Computer A's terminal.

🧑‍💻 Student Practical Task – Linux Terminal and SSH

Work with another student if possible. Both Linux computers should be able to communicate over the network.

Required journey: Find IP → Ping → Try SSH → Run Linux commands → Screenshot.

Part 1 · Find Computer B's IP address

On Computer B, open Terminal:

hostname -I

Part 2 · Test the connection from Computer A

ping <Computer_B_IP>

Replace the placeholder with the actual IP. Press Ctrl + C to stop.

Part 3 · Try SSH from Computer A

ssh <username>@<Computer_B_IP>

Replace the username and IP with Computer B's details. If prompted, verify the host key, accept it, and enter the password.

Part 4 · Execute Linux commands

If SSH works: run these commands in the remote terminal:

hostname
whoami
pwd
ls

Then disconnect using exit.

If SSH does not work: run hostname, whoami, pwd, and ls in your own Linux Terminal. You must still complete and submit the task.

📸 Required Screenshot – ONE screenshot

If SSH works: show the successful SSH session and at least two remote commands with their results.

If SSH does not work: show all four Linux commands and their results in your own Terminal.
