1. What does IoT security protect?

IoT security is not just a password. It protects devices, messages, accounts, software, and the people who depend on the system.

Confidentiality 🔒

Only authorized parties can read private information.

Integrity ✅

Data and commands must not be altered without authorization.

Availability ⚡

Devices and services should work when they are needed.

2. Six security practices

Authentication

Verify who the user or device is.

Authorization

Decide what that identity may do.

Encryption

Protect messages in transit and sensitive data at rest.

Secure updates

Apply verified firmware patches and maintain supported devices.

Network segmentation

Separate less-trusted IoT devices from sensitive systems.

Monitoring

Detect suspicious access and unusual behavior.

Q1. Explain confidentiality, integrity, and availability using a smart-home example.

Confidentiality: only authorized users can view camera video. Integrity: commands such as “unlock door” cannot be secretly changed. Availability: alarms and local safety functions remain usable when needed.

Q2. A school has 40 IoT cameras with default passwords. Recommend four security improvements and explain why.

Replace default passwords with unique strong credentials; limit who can access cameras; apply supported security updates; isolate cameras on a dedicated network. These steps reduce unauthorized access, exploitation, and spread of attacks.

Q3. Design a secure path for a temperature sensor to send MQTT data to a dashboard.

The sensor authenticates to a trusted MQTT broker over TLS. The broker grants publish permission only to the sensor's topic. The dashboard authenticates separately and receives only authorized topics. Keep firmware updated and monitor unusual connection attempts.

Key takeaway

Secure IoT = trustworthy identities + protected communication + limited permissions + maintained devices + monitoring. Security is an ongoing process, not a single switch.
