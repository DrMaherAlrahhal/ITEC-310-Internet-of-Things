1. What are we learning?

Last week, we switched an LED ON and OFF. This week, we will make the same LED look dim, medium, or bright.

What is PWM?

PWM = Pulse Width Modulation. Arduino switches the LED ON and OFF very quickly. Changing the percentage of time it stays ON changes how bright it looks.

More ON time → Brighter LED

Which Arduino function do we use?

Lab 4: Blinking

digitalWrite(9, HIGH);

digitalWrite(9, LOW);

Manually switches LED ON and OFF.

Lab 5: PWM

analogWrite(9, 128);

Uses a PWM value between 0 and 255 to control brightness.

Important: Despite its name, analogWrite() on an Arduino Uno PWM pin produces a digital signal switching rapidly between LOW and HIGH. It does not output a continuously variable analog voltage. Use a PWM-capable pin such as D9.

2. What is the difference between blinking and PWM?

Both methods switch an LED ON and OFF. The difference is how fast they switch and what you see.

Lab 4 – Blinking LED

ON for 1 second → OFF for 1 second

LED ON

You can clearly see the LED switching ON and OFF.

Lab 5 – PWM LED

Very fast ON/OFF → Adjustable brightness

Medium brightness

The switching is too fast to see individually. You see the brightness instead.

Simple comparison

Think of clapping: One clap every second is easy to notice (blinking). Very fast switching is harder to notice individually (PWM). The average ON time determines how bright the LED appears.

3. What do 0, 64, 128, and 255 mean?

These are PWM values, not volts or seconds. Arduino uses the range 0–255 to choose the percentage of each PWM cycle that the LED stays ON.

Why these percentages?

ON time (%) ≈ PWM value ÷ 255 × 100

Example: 64 ÷ 255 × 100 ≈ 25%. This means the LED is ON for approximately one quarter of each very fast PWM cycle.

Think of 100 tiny equal time slots: value 64 means ON for about 25 of them, while value 128 means ON for about 50. This is an illustration of duty cycle, not 100 separate Arduino commands.

5. Build and Run in Wokwi

Components

Arduino Uno, LED, 220 Ω resistor, and connecting wires.

Connections:

Arduino D9 → 220 Ω resistor → LED anode (+)

LED cathode (−) → Arduino GND

Connect the resistor and LED in series. The longer LED leg is usually the anode.

  1. Open wokwi.com.
  2. Create an Arduino Uno project.
  3. Add an LED and 220 Ω resistor.
  4. Connect the LED circuit to D9 and GND.
  5. Paste the code and start the simulation.

Starter Code – Medium Brightness

int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  analogWrite(ledPin, 128); // Medium brightness
}

Change 128 to 64 or 255 to compare brightness.

Example – Alternate Dim and Bright (Task 3)

int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  analogWrite(ledPin, 64);  // Dim
  delay(1000);
  analogWrite(ledPin, 255); // Bright
  delay(1000);
}

Optional Example – Smooth Fade

int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  for (int brightness = 0; brightness <= 255; brightness += 5) {
    analogWrite(ledPin, brightness);
    delay(30);
  }

  for (int brightness = 255; brightness >= 0; brightness -= 5) {
    analogWrite(ledPin, brightness);
    delay(30);
  }
}

The first loop increases brightness; the second decreases it. Change delay(30) to delay(15) to make fading faster.
