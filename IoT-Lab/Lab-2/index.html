1. Arduino Uno

Connection: Digital pin 13 → 220–330 Ω resistor → LED anode (+); LED cathode (−) → GND.

Language: Arduino C/C++. setup() runs once and loop() repeats.

void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

2. Raspberry Pi 3B

Connection: GPIO 18 (physical pin 12) → 220 Ω resistor → LED anode (+); LED cathode (−) → GND (e.g. physical pin 14).

Language: Python with RPi.GPIO. BCM 18 is not physical pin 18.

import RPi.GPIO as GPIO
import time

LED = 18
GPIO.setmode(GPIO.BCM)
GPIO.setup(LED, GPIO.OUT)
try:
    while True:
        GPIO.output(LED, GPIO.HIGH)
        time.sleep(1)
        GPIO.output(LED, GPIO.LOW)
        time.sleep(1)
except KeyboardInterrupt:
    pass
finally:
    GPIO.cleanup()

4. Student practical work

Complete these four activities in Tiffany Sandbox. Take a screenshot showing your circuit, code and output for each task.

Task 1.1 — Arduino LED circuit (Easy)

Create or open Arduino Uno + LED. Connect pin 13 through a 220–330 Ω resistor to the LED and connect its cathode to GND. Make it blink every second.

Task 1.2 — Arduino different delays (Easy)

Modify the Arduino program: LED ON for 2 seconds, OFF for 0.5 second, then repeat. Hint: delay(2000) and delay(500).

Task 2.1 — Raspberry Pi LED (Medium)

Open Raspberry Pi + LED in Tiffany Sandbox. Use BCM GPIO 18 to turn the LED ON, wait 2 seconds, then turn it OFF. Take a screenshot.

Task 2.2 — Raspberry Pi repeating blink (Medium)

Modify your Python program: ON → wait 1 second → OFF → wait 1 second → repeat. Take a screenshot.
