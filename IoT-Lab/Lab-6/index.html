Learn how an Arduino reads a DHT22 sensor, displays temperature and humidity in the Serial Monitor, and uses readings in simple calculations.

1. What are we measuring?

🌡️ Temperature

How hot or cold the surrounding air is. We measure it in degrees Celsius (°C).

Example: 25°C

💧 Humidity

How much water vapor is in the air. The sensor reports relative humidity (%).

Example: 60% RH

🏡 Why IoT needs both

A smart greenhouse can monitor temperature and humidity and send alerts when the environment changes.

Key idea: The DHT22 sensor measures both values. Arduino reads the sensor and displays them; we do not calculate humidity from temperature alone.

Air→DHT22 sensor→Arduino Uno→Serial Monitor

Arduino code – read temperature and humidity

#include <DHT.h>

#define DHTPIN 2
#define DHTTYPE DHT22
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float temperature = dht.readTemperature();
  float humidity = dht.readHumidity();

  if (isnan(temperature) || isnan(humidity)) {
    Serial.println("Sensor reading failed");
  } else {
    Serial.print("Temperature: ");
    Serial.print(temperature);
    Serial.print(" C | Humidity: ");
    Serial.print(humidity);
    Serial.println(" %");
  }
  delay(2000);
}
dht.readTemperature()

Read air temperature in °C.

dht.readHumidity()

Read relative humidity in %.

Serial.print()

Display readings in Serial Monitor.

delay(2000)

Wait 2 seconds before the next reading.
